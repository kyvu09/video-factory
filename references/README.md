# Thư mục Tài liệu & Chỉ dẫn (References)

Thư mục này lưu trữ các tài liệu tra cứu kỹ thuật, nguyên tắc sư phạm và kỹ năng hướng dẫn cho AI:

1. **[`manim-gl-api.md`](./manim-gl-api.md)**:
   - Bảng tra cứu cú pháp chuẩn của ManimGL 1.7+ (đối tượng, căn chỉnh, animation, camera).
   - Dùng để tham chiếu khi viết code hoặc đính kèm vào prompt để AI không bị nhầm sang ManimCE.

2. **[`storytelling.md`](./storytelling.md)**:
   - Các nguyên tắc sư phạm trực quan: Cấu trúc 3 hồi (Hook ➔ Build ➔ Resolution), bảng màu ngữ nghĩa, nhịp độ hiển thị và giới hạn số từ trên màn hình.

3. **[`ai-animation-skill.md`](./ai-animation-skill.md)**:
   - Toàn bộ chỉ dẫn hệ thống (System Prompt) chuẩn để giao việc cho AI (Claude, Gemini, ChatGPT...) biến chủ đề bài học thành kịch bản phân đoạn 15s và code ManimGL.

4. **[`math-visual-recipes.md`](./math-visual-recipes.md)**:
   - Tổng hợp các công thức trực quan hóa toán học thông dụng (Đạo hàm tiếp tuyến, Tổng Riemann xấp xỉ diện tích, Mặt tròn xoay 3D) và bảng đối chiếu cú pháp ManimCE sang ManimGL.
